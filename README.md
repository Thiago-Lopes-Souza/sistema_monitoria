# sistema_monitoria

Um sistema desenvolvido em Python para consulta e agendamento de monitorias por matéria, do curso de Engenharia de Sistemas da UFMG.

**O protótipo fica na pasta [`prototipo_monitoria/`](prototipo_monitoria/).** Entre nela antes de rodar qualquer comando:

```
cd prototipo_monitoria
python -m monitorias                      # inicia o menu
python -m unittest discover -s tests -v   # roda os testes
```

As instruções completas (versão do Python, dados fictícios e cenários) estão em
[`prototipo_monitoria/README.md`](prototipo_monitoria/README.md).

Fora do ZIP de entrega: `EVIDENCIAS.md` (resultados dos cenários) e `docs/` (diagramas).
O ZIP enviado contém **só** a pasta `prototipo_monitoria/`, sem `cenarios/saidas/`.
